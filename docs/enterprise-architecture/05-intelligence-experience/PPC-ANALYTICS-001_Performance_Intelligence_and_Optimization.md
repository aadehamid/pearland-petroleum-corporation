## 1. Authority and methods

EPM defines KPI meaning. PPC's qualified computation calculates values and effects. Physical engineering ([ENG-001](../02-industrial-engineering/PPC-ENG-001_Physical_and_Numerical_Engineering.md), `EQ-01`–`EQ-09`) constrains feasible outcomes. A graph path identifies candidates for analysis, not a numerical effect. Forecasting, counterfactual simulation, process diagnosis, optimization and causal estimation are different methods and require different evidence. Under [ADR-0048](../../adr/0048-pyomo-optimization-and-langgraph-pydantic-agents.md), **Pyomo with HiGHS** (extending to **IPOPT** when nonlinear blending or kinetics enter) replaces OR-Tools as PPC's optimization modeling stack; MLflow, StatsForecast/MLForecast, DoWhy/EconML, and PyMC remain the staged analytics/ML lifecycle tools. The system has no authority over a real facility.

`ModelRun` requires run ID, method class, model/formula/parameter digests, branch, subject scope, actor/role, channel, purpose and access scope, effective time, knowledge cutoff, world and product release IDs, horizon, grain, units, measurement basis, input digest, input provenance, output provenance class, epistemic status, lifecycle status, released-at time, seed, solver configuration, feasibility status, uncertainty representation and output digest. A result transitions `DRAFT → VALIDATED|FAILED|OUT_OF_ENVELOPE|INFEASIBLE`, `VALIDATED → RELEASED|FAILED`, and `RELEASED → SUPERSEDED`. Failure states are terminal for the run ID; a corrected input creates a new run. Invalid inputs, out-of-envelope parameters or an infeasible solver return the corresponding status and diagnostics, never a persuasive point estimate. A scenario input is `SCENARIO_ASSUMPTION`; a forecast is `ESTIMATED`; a deterministic calculation over a synthetic world is `DERIVED` with synthetic lineage.

## 2. Worked alternatives

For Scenario A (`SCN-A-T125`, `UC-1`/`UC-3`), the nominal HCU charge is `40,000 bbl/day` VGO (`5,781.4 t/day` at $\text{SG}=0.910$) and the `08:10 UTC` recycle-gas compressor derate (`EQ-05`) caps feasible HCU feed at `30,000 bbl/day` (`4,336.1 t/day`) against the `36,000 bbl/day` plan (or `3,750 t/day` $\approx 25,945\text{ bbl/day}$ if shared $\text{H}_2$ headroom is `75 t/day` under `EQ-07`). A `SCENARIO_ASSUMPTION` proposal to feed `30,001 bbl/day` is infeasible and returns `INFEASIBLE` with the binding compressor/$\text{H}_2$ constraint. Downstream ULSD production, volumetric gain, blending spec compliance (`EQ-08`), and commercial margin (`EQ-09`) are computed through the coupled Pyomo model rather than multiplying feed barrels by a fixed yield scalar. (The earlier `100,000 → 80,000 bbl/day` `CAP-ILLUS-01` scratch illustration is retired in favor of the single reconciled `SCN-A-T125` fixture.)

An optimizer can compare no action with a `SCENARIO_ASSUMPTION` 5,000 bbl spot purchase or a max-distillate CDU/VDU cut-point swing (`UC-4`). Any alternative is feasible only if location, timing, blend specs (`EQ-08`), tank working bounds (`EQ-02`), credit, and approvals pass. Fair backcasting (`UC-3`, `EQ-09`) decomposes $\Delta\Pi$ into LP calibration effect, decision-time opportunity, and execution/exogenous residual using separate pinned `ModelRun` IDs. A duplicate model run with identical input digest, method class, model/formula/parameter digests, horizon, grain, units, measurement basis, seed, solver configuration, actor/role, channel, purpose, access scope, branch, subject scope, effective time, knowledge cutoff and pinned releases returns the same result ID or an explicitly equivalent reproducible result. A late input creates a new run; an old decision keeps its original model result. A restricted contract cannot enter a planner's optimization or leak through an option list. A sibling branch's capacity cannot enter baseline.

## 3. Qualification and decisions

Check dimensions, independent conservation oracle, envelope crossings, objective sign, known feasible/infeasible Pyomo LP/NLP cases, solver tolerance, seed replay, backtest against held-out synthetic history, temporal leakage, branch isolation and permission filtering (`PO-05`–`PO-12`). For a causal claim, record intervention definition, assumptions, confounders, identification strategy and sensitivity analysis; a simulated difference alone is a model counterfactual. Store exact inputs, expected/observed outputs, versions and reviewer disposition. None is reported as executed (**planned**).
